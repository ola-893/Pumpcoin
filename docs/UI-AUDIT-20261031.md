# Pump UI audit · October 31, 2026

The primary journey is **explore → inspect identity and history → review investment → return and redeem**. Agent controllers also need **register → inspect saved profile → manage research/vault permission**. Protocol infrastructure stays in the operator CLI.

## References actually inspected

Mobbin's public [reference library landing page](https://mobbin.com/) supplied these examples. The authenticated `/discover` library redirected to login, so this audit does not claim access to its private flows or premium collections.

| Mobbin example | Observed pattern | Application in Pump |
| --- | --- | --- |
| Fey Web · clean dashboards | Summary panels above a distinct transaction history; secondary sections in tabs | One investor overview, separate vault activity and practice tabs |
| Cash App iOS · multi-step forms | Visible progress, one clear continuation, short supporting copy | Preserve the three registration steps; move exports/draft saving out of the primary action sequence |
| Phantom iOS · onboarding | One prominent primary action and a quieter alternative | Keep MetaMask first; disclose other wallets/passkeys on demand; one profile destination after registration |

The exact public image URLs and local inspection metadata are listed in [the reference manifest](testing/ui-audit-20261031/references.json). Images were viewed for design research; no third-party screenshot, logo or financial number was copied into Pump.

## Findings and repairs

| Surface | Friction found | Repair |
| --- | --- | --- |
| Directory | Repeated practice badges and a signed-version counter competed with agent selection | One practice status per card; retain model/pair and recorded vault linkage; simplify directory scope copy |
| Unbound profiles | A disabled chain query could leave the overview saying it was reading a vault forever | Render a clear “No vault linked yet” state and a controller-only setup continuation |
| Profile navigation | A practice/funded switch changed the meaning of four tabs and hid investment | One overview; stable Vault activity, Research & practice, Identity & evidence tabs; investment card on overview |
| Operator controls | Research run/start/stop appeared in investor-facing panels | Controller-only Manage agent workspace and research runtime controls, requiring the declared controller and chain in the connected UI |
| Provenance | Full hashes, runtime detail and export controls dominated the overview | Keep identity/model/current vault summaries visible; preserve exact commitments, measurements, original captures and source limits in named disclosures |
| Research | Same panel repeated across overview/history/evidence; eight metrics appeared before the latest outcome | Compact overview summary; one complete practice page with accounting/history/source details on demand; all five inference errors remain visible |
| Investment | Amount entry and price-maintenance controls appeared before readiness | Show connect/readiness first; expose the amount flow when ready or shares exist; retain exact quotes, minimums, deadlines and pending-receipt recovery |
| Registration | Saving/exporting a draft competed with checking/signing; full research setup appeared immediately after registration | Draft/export disclosure; saved-registration success state with a profile CTA; setup continues in the controller workspace |
| Wallet | Browser-wallet and passkey options competed with MetaMask | MetaMask remains primary; other browser wallets and passkey options are expandable |
| Portfolio route | Unimplemented aggregate stats and an unsigned operator draft looked like investor holdings | Remove placeholder stats/draft management; direct users to the actual per-agent share balances |
| Network copy | Current Sepolia views still said Monad/MON | Derive current network labels from the execution configuration and observed chain; preserve the source link after checking it against the actual Git remote |
| Product copy | Roadmap/implementation prose distracted from tasks | Replace “coming soon” promotion with specific current evidence limits; preserve risks and uncertainty near relevant decisions |

UI controller gating is a presentation boundary, not a replacement for server checks or wallet/contract authority. No private key is sent to the UI. No infrastructure-creation control was added.

## Data and behavior preserved

- Signed manifests, authorizations, policy, source captures, model exchanges, ledger history and on-chain receipts are unchanged by this audit.
- Exact evidence remains inspectable and exportable. Missing NAV, incomplete history, inference failures, stale snapshots and independent runtime failures are not converted into success badges.
- Deposits remain capital. Practice capital and returns remain separate from Pump-share accounting. Five failed cycles do not become five successful model decisions.
- Wallet transaction validation, limited approvals, quote expiration, minimum output and durable pending hashes remain in place.
- Historical chain labels follow their signed record; marketing uses the configured active network.

## Second pass: copy reduction

The follow-up removes repeated prose rather than shrinking its font:

- Directory: direct heading, shorter filters, model/pair tags and one practice status; full strategy remains on the profile.
- Profile: short tabs, compact identity links, declared limits and key vault numbers first. Balances, coverage, source boundaries and runtime details are expandable.
- Research: short summary and explicit failure counts; original model exchanges, source observations, signatures and accounting remain inspectable.
- Registration: direct title, three short step labels, fewer hints, network details collapsed. Private-key guidance, local-inference scope and immediate-change demo terms remain explicit.
- Investment and management: shorter status/helper text; exact transaction scope, amounts, minimum output, gas, expiry, deadlines, blockers and recovery remain intact.
- Homepage: introduction plus inspect/invest/redeem; repeated marketing sections and footer prose removed.

For this copy pass, production build, root typecheck, lint (11 existing warnings), diff whitespace checks and the current signed-checkpoint replay passed. Chrome checks covered directory filtering, registration, homepage, profile tabs, five preserved inference failures and the original manifest commitment in its disclosure. The 207-test suite above belongs to the preceding audit; it was not rerun for this text/disclosure-only follow-up. Connected-wallet transaction execution and mobile emulation were not repeated in this pass. No model inference, signing or on-chain transaction was requested.
